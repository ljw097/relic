# Relic 1.2.1

This release fixes bugs in `relic diff`, which came out in 1.2.0.

## Download

| System | File |
|---|---|
| Windows (x86-64) | `relic-1.2.1-windows-x86_64.exe` |
| Linux (x86-64) | `relic-1.2.1-linux-x86_64.tar.gz`: one file, `relic` |
| macOS, Apple silicon | `relic-1.2.1-macos-arm64.zip`: `Relic.app` |
| macOS, Intel | `relic-1.2.1-macos-x86_64.zip`: `Relic.app` |

The macOS app isn't signed, so right-click it and choose Open the first time. The wheel is
attached too, for pip (Python 3.10+).

## Fixed

**A block added near the start of a function made all of it look changed.** Code is compared
block by block, and adding one block (an early `if (x < 0) return -1;`, say) renumbered every
block after it. Each branch to one of those blocks then looked different too. A function with
that one-line change scored 58% alike, and `-f` listed almost every line as removed and added
again. Block numbers are now left out when functions are compared and when the diff lines up
their lines. The same function now scores 94% alike, and `-f` shows just the six lines that
were added.

**`relic diff -f FUNC -d` crashed when a function couldn't be decompiled.** It printed a Python
traceback. Now that side of the diff shows `// not decompiled (...)`, and the other side's
pseudocode is still shown.

**Matches found by similarity alone didn't lead anywhere.** The callees and callers of a
matched function are tried next, but only for matches found by identical code or by name.
Matches found in the last, similarity-only pass are now followed through the call graph too.

**A function called from everywhere could make the diff very slow.** Comparing the callers of
a hub like `xmalloc` against each other is now capped. The last pass finds those callers
anyway.

## Releases

Every release now comes with SHA-256 hashes: a `SHA256SUMS` file among the downloads, and the
same list at the end of the release notes. To check what you downloaded, run
`sha256sum -c SHA256SUMS --ignore-missing` (on macOS, `shasum -a 256 -c SHA256SUMS`).

The Release workflow has a new **add missing** option. It rebuilds an existing release from
its tag and uploads only the files the release is missing. 1.2.0 went out without its macOS
Apple-silicon build because that runner never started; this option adds it, along with
hashes for every 1.2.0 file.
