# Relic 0.2.0 (beta)

Relic now ships as a program you download and run: one executable for Windows, Linux and macOS,
no Python needed. It opens with no file; open one from File > Open (`Ctrl+O`), File > Open Recent,
or by dropping it on the window. Overall progress against the goal (IDA Pro 9 + Hex-Rays) is about
83%, up from 76%.

## Download

| System | File |
|---|---|
| Windows (x86-64) | `relic-0.2.0-windows-x86_64.exe` |
| Linux (x86-64) | `relic-0.2.0-linux-x86_64.tar.gz`: one file, `relic` |
| macOS, Apple silicon | `relic-0.2.0-macos-arm64.zip`: `Relic.app` |
| macOS, Intel | `relic-0.2.0-macos-x86_64.zip`: `Relic.app` |

The macOS app is not signed: the first time, right-click it and choose Open. The same executable
runs the command-line tools too (`relic info FILE`, `Relic.exe decompile FILE`, ...). The wheel is
still here for installing with pip (Python 3.10+).

## New since 0.1.0

- **File formats**: Mach-O — executables, dylibs, bundles, universal files, relocatable objects,
  chained fixups (macOS 12+), checksec — and Objective-C: method names from the class metadata
  (stripped binaries too), message sends shown as `[obj speak:"woof" times:n]`, `self` / `_cmd`
  parameters, `self->ivar`.
- **Processors**: MIPS big-endian and MIPS64 (n64), PowerPC 32-bit and 64-bit (ELFv2), RISC-V RV32.
- **Debugger**: Windows programs debugged under wine with Windows' own `gdbserver.exe`; RV32 under
  qemu.
- **Auto-analysis**: `.eh_frame` as the list of functions (99.9% of them found in stripped bash),
  switch tables gcc sets up out of sight of the jump, negative case ranges, tail calls through
  function pointers. Unresolved indirect jumps in stripped bash: 103 → 12.
- **Decompiler**: Apple's arm64 calling convention, clang's division and stack-protector idioms,
  RV32 doubles passed in register pairs.
- **GUI**: starts empty and opens a file dropped on the window.

## Known limits

- No x87 floating point and no by-value struct arguments or returns in the decompiler.
- The debugger needs `gdb` (and `qemu-user` / wine for other systems' programs).
