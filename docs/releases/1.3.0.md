# Relic 1.3.0

This release carries your work over to a new build: the names, comments and variable names you
gave the old one go to the functions `relic diff` matches in the new one.

## Download

| System | File |
|---|---|
| Windows (x86-64) | `relic-1.3.0-windows-x86_64.exe` |
| Linux (x86-64) | `relic-1.3.0-linux-x86_64.tar.gz`: one file, `relic` |
| macOS, Apple silicon | `relic-1.3.0-macos-arm64.zip`: `Relic.app` |
| macOS, Intel | `relic-1.3.0-macos-x86_64.zip`: `Relic.app` |

The macOS app isn't signed, so right-click it and choose Open the first time. The wheel is
attached too, for pip (Python 3.10+). `SHA256SUMS` lists the hashes of every file.

## New

**Port annotations from an older build** (`relic diff OLD NEW --port`, File > Port from older
build, `port_from()` in scripts). When a new version of something you already reversed comes
out, every function `relic diff` matches gets:

- its name: yours, or the old build's symbol when the new build is stripped;
- the comments, bookmarks and number formats on the instructions that didn't change (the code
  of the two functions is lined up line by line; what was on changed code is counted, not
  guessed at);
- its repeatable comment;
- the names and types of its decompiler variables: all of them when the code is identical,
  only the arguments when it changed (`v3` in one build need not be `v3` in the other).

Globals that unchanged instructions refer to get their old names too. What the new build already
has (your names and comments, its own symbols) is kept unless you pass `--overwrite`, and a name
already used in the new build isn't given to a second function. The CLI saves the result to the
new build's project file (`--no-save` only lists it); in the GUI it is one undo step and the old
build is analysed in the background.

```
$ relic diff chall chall_fixed --port
0x40133b  add_note
0x401539  hash_string
0x40160c  read_name
0x4040a0  notes  (global)
ported 3 function name(s), 1 global(s), 2 comment(s), 1 on changed code not placed
saved chall_fixed.relic.json
```

On bash against itself, porting the annotations of 2,296 matched functions takes a quarter of a
second after the diff.
