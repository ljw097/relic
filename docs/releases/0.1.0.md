# Relic 0.1.0 (베타)

리버싱과 포너블을 위한 GUI 디스어셈블러·디컴파일러 Relic의 첫 릴리스입니다. 베타입니다: 핵심
경로(적재 → 분석 → 디컴파일 → GUI·디버거)는 실사용 가능하지만, 출력 형식과 Python API는
다음 버전에서 바뀔 수 있습니다. 목표 대비 진행률(IDA Pro 9 + Hex-Rays 기준)은 전체 약 76%입니다.

## 설치

```sh
python3 -m venv .venv
.venv/bin/pip install relic_re-0.1.0-py3-none-any.whl     # 아래 Assets의 wheel
.venv/bin/relic gui ./binary
```

Python 3.10 이상(Linux). 의존성 capstone·pyelftools·pefile·PySide6는 함께 설치됩니다. 디버거는
`gdb`(다른 아키텍처는 `gdb-multiarch`와 `qemu-user`), 어셈블해서 패치하기는 `pip install 'relic-re[asm]'`.

## 들어 있는 것

- **파일 포맷**: ELF(실행·공유·재배치 객체·코어 덤프), PE(import/export/지연 import, COFF 심볼,
  .pdata, TLS 콜백, 리소스·버전 정보, PDB 경로, .NET 감지), COFF 객체, 정적 라이브러리 멤버
  (`lib.a:member.o`), Intel HEX·S-record, raw(적재 주소 추정 `--base auto`)
- **프로세서**: 디스어셈블 x86·x64·ARM/Thumb·AArch64·MIPS·RISC-V·PPC; 분석·디컴파일
  x86/x64·ARM32·AArch64·MIPS32·RV64GC
- **분석**: 재귀 하강 + 프롤로그 스캔, 점프 테이블 → `switch`, 데이터 xref, noreturn, stripped
  `main` 복구, 컴파일러·런타임 식별(GCC/clang/MSVC/MinGW/rustc/Go, glibc/musl/msvcrt)
- **라이브러리 식별**: FLIRT 방식 시그니처(`relic sigs build`, 설치된 툴체인에서 자동 생성
  `--system`), stripped 정적 바이너리에서 심볼 있는 함수의 83~94%에 이름, 오식별 0
- **디컴파일러**: 구조화(if/while/for/switch/&&), 구조체 자동 복원과 대화형 재타입(`Y`),
  SSE·AArch64·VFP·RISC-V 부동소수점, libc·Windows API 타입 라이브러리, C 헤더 가져오기,
  재컴파일 검증 하네스
- **GUI**: 리스팅·CFG 그래프·의사 코드·헥스, xref·이름·주석·북마크, 검색, 바이트 패치(내보내기),
  모든 편집의 undo/redo, 구조체·타입 창, 시그니처 창, 테마
- **디버거**: GDB/MI 기반 — 로컬, gdbserver, qemu-user(ARM·AArch64·MIPS·RISC-V), 실행 중인
  프로세스에 붙기, 스레드·모듈·시그널·명령 추적, 레지스터·스택 telescope·vmmap·glibc 힙 뷰
- **스크립팅·확장**: Python API·콘솔, `relic script` 배치 실행, 플러그인(메뉴·훅·파일 로더·
  프로세서 모듈)
- **프로젝트·협업**: `<binary>.relic.json`, 스냅숏, 버전 기록, 병합, Lumina 대응 메타데이터 공유
- **포너블**: checksec(ELF/PE), 위험 함수·비상수 포맷 스트링·ret2win 후보
